03 / TASK EXECUTION

Every task should have a clear action
and a clear outcome.

FEATURED TASK

Coordinate Supplier & Request Quote

Phase 1 — Onboarding & Procurement
DESCRIPTION

Coordinate with the appropriate supplier to confirm production capability, pricing, and estimated timeline.

ACTIVITIES
  • Send project requirements to supplier
  • Request quotation
  • Confirm supplier availability / capacity
  • Confirm estimated production time
  • Confirm material / production requirements
  • Record supplier response
  • Compare supplier response with client requirements
  • Flag conflicts or limitations
OUTPUT / DONE WHEN

Supplier capability, quotation, and preliminary timeline are documented.

04 / TIMELINE & DEPENDENCIES

A production project needs both
a schedule and a sequence.

Dependencies make the workflow functional — they show what must happen before another task can properly proceed. Dates without dependencies are just a list. Dependencies without dates are just logic. Together, they create a manageable production schedule.

Dates — when work is planned
Dependencies — what must happen first
Statuses — what is happening now

ADAPT THE SYSTEM TO THE BUSINESS

A good PM system should support
the client's workflow — not unnecessarily replace it.

This ClickUp setup is a proposed workflow based on the responsibilities in the job posting. In an actual engagement, I would first take time to understand how the business already operates before designing any system.

BEFORE BUILDING ANY SYSTEM, I WOULD FIRST UNDERSTAND:
→ How the company currently communicates with suppliers
→ How production updates are collected and tracked
→ How approvals are handled internally
→ How client revisions are managed
→ How shipping is coordinated
→ How project documentation is maintained
→ Who owns each responsibility
→ What tools are already being used
